# SIPELITA — Portal Layanan Terintegrasi Puskesmas

Prototype website berbasis Next.js.

## Menjalankan
1. Install Node.js.
2. Buka terminal di folder project.
3. Jalankan `npm install`
4. Jalankan `npm run dev`
5. Buka `http://localhost:3000`

## Halaman
- `/` Portal utama
- `/pendaftaran` Pendaftaran online (prototype)
- `/antrean` Cek antrean
- `/jadwal` Jadwal
- `/informasi` Informasi
- `/pengaduan` Pengaduan
- `/kontak` Kontak
- `/login` Login (UI prototype)
- `/admin` Dashboard admin (UI prototype)

## Catatan
Versi ini adalah prototype frontend. Authentication, PostgreSQL/Supabase, Row Level Security, data real-time, dan deployment produksi belum dihubungkan.
Gunakan data dummy selama pengembangan dan jangan memasukkan data pasien nyata tanpa otorisasi yang sesuai.
